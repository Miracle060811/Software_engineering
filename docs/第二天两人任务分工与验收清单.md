# TravelMate 第二天两人任务分工与验收清单

## 1. 今日总目标

两人配合 AI，在一天内完成 UC01—UC19 的文档与设计追溯初版，使每个业务场景都能对应：

`REQ → UC → SYS → COMP → OBJ → 代码 → 数据表 → 测试状态/证据`

- Mermaid 源文件与图片一一对应，文档只使用仓库相对路径。
- `npm run check:traceability` 通过。
- 保存 CI、看板、站会和 Git 标签等项目证据；无法取得的证据明确标为待补，不得虚构。

## 9. AI 使用规则

AI 可以用于批量生成用例模板、Mermaid 初稿、追溯表结构和一致性检查，但每项内容必须由负责人对照当前代码复核。

以下内容不得直接采用 AI 推测：

- 不存在的 Controller、Service、Mapper 或 API；
- 未实现的预订、支付、退款或核销流程；
- 未执行的 UNIT、INT、E2E 测试结果；
- GitHub Actions、看板、教师确认或运行截图；
- 当前未部署的微服务、Docker、Kubernetes 或 CD 能力。

最终原则：宁可真实标注“待确认、partial、planned”，也不能为了填满追溯表而虚构完成状态。
