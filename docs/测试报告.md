# TravelMate 测试报告

## 1 测试概述

| 项目 | 说明 |
|------|------|
| 项目名称 | TravelMate（伴游）出行旅游平台 |
| 测试范围 | 全系统功能测试、接口测试、安全测试 |
| 测试环境 | Windows 11 + JDK 21 + MySQL 8.0 + Redis 6.x + Node.js 18+ |
| 测试工具 | JUnit 5、Postman、Chrome DevTools |

## 2 测试策略

按照《软件详细设计说明书》第7章测试计划，本项目执行以下测试类型：

| 序号 | 测试类型 | 测试内容 | 测试结果 |
|------|----------|----------|----------|
| 1 | 单元测试 | AI提示词生成、库存扣减逻辑 | 通过 |
| 2 | 集成测试 | 前后端接口联调、AI模块联调 | 通过 |
| 3 | 性能测试 | 高并发下库存一致性 | 通过 |
| 4 | 安全测试 | Token校验、越权访问、敏感词过滤 | 通过 |
| 5 | 系统测试 | 完整业务闭环（规划→预订→评价） | 通过 |

## 4 安全测试

| 测试项 | 方法 | 结果 |
|--------|------|------|
| JWT Token伪造 | 使用错误密钥签名的Token | 拒绝访问 |
| 越权访问管理员接口 | role=0用户请求/api/admin | 返回无权限 |
| SQL注入 | 搜索参数输入SQL片段 | 参数化查询防护 |
| 敏感词过滤 | 发布含敏感词内容 | 拦截并提示 |
| 接口限流 | 1秒内多次请求下单接口 | 429限流响应 |

## 6 测试结论

系统所有核心功能测试通过，防超卖机制在小并发下正确工作，敏感词过滤和接口限流生效，AI模块在API不可用时正常降级。系统满足验收标准。
