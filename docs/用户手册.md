# TravelMate 用户手册

## 1 系统简介

TravelMate（伴游）是一个集机票预订、酒店住宿、火车票购买、AI 智能行程规划、旅行社区于一体的综合出行旅游平台。覆盖用户"行前规划-行中服务-行后分享"的全旅程场景。

## 2 快速开始

### 2.1 访问系统

在浏览器中打开 `http://82.156.91.79:42356/`。

### 2.2 注册与登录

1. 点击首页右上角"登录/注册"
2. 输入用户名和密码
3. 首次使用点击"注册"创建账号

### 2.3 首页

首页提供统一的搜索入口，包含三个 Tab：

- **机票**：输入出发城市、到达城市、出发日期搜索航班
- **火车票**：输入出发站、到达站、出发日期搜索列车
- **酒店**：输入城市、日期筛选酒店

## 3 大交通票务

### 3.1 搜索航班

1. 在首页选择"机票"Tab
2. 输入出发城市（如"北京"）和到达城市（如"上海"）
3. 选择出发日期
4. 点击"搜索"查看结果，包括航司、航班号、时间、价格、余票

### 3.2 预订机票

1. 在搜索结果中点击"预订"
2. 选择乘客（从常用旅客列表中选择，或添加新乘客）
3. 选择舱位（经济舱/商务舱）
4. 确认下单

### 3.3 搜索火车票

1. 选择首页"火车票"Tab
2. 输入出发站和到达站（如"北京南"-"上海虹桥"）
3. 选择出发日期，点击搜索
4. 结果列表展示车次号、出发/到达时间、历时、各席别余票与票价

### 3.4 候补抢票

1. 在搜索结果页目标车次的余票为 0 时，点击"加入候补"
2. 系统将你加入候补队列，余票出现时自动推送站内通知
3. 可在"我的订单"中查看候补状态

### 3.5 价格历史走势

在航班或火车搜索结果中，点击票价旁的图表图标可弹出近 7 日价格走势图（ECharts），帮助判断当前票价高低。

### 3.6 订单管理

- 导航到"我的订单"页面查看所有订单
- 待支付订单可执行"去支付"或"取消"
- 已支付订单显示出票状态
- 超时 15 分钟未支付订单自动取消

### 3.7 常用旅客

在预订弹窗中可添加常用旅客信息（姓名、身份证号、手机号），下次预订时直接选择。

### 3.8 优惠券中心

- 导航到“优惠券中心”查看当前可领取的满减券/折扣券
- 点击“领取”后，优惠券会进入“我的优惠券”列表
- 符合使用条件的交通订单可在下单过程中选择优惠券抵扣

## 4 酒店住宿

### 4.1 搜索酒店

1. 在首页选择"酒店"Tab
2. 输入城市、可选入住/退房日期
3. 可选按星级、价格区间筛选
4. 查看搜索结果

### 4.2 酒店详情与预订

1. 点击酒店卡片查看详情
2. 查看房型列表（房型名称、床型、面积、价格、可用房间数）
3. 选择房型，填写入住/退房日期
4. 填写入住人姓名和联系电话
5. 确认下单

### 4.3 景点门票

- 导航到"景点门票"页面
- 按城市搜索景点
- 查看景点详情（地址、票价、开放时间、热度）
- 选择购票数量，确认下单，订单凭证可在"我的订单"中查看

### 4.4 一日游 / 周边游产品

- 在景点页面切换到"周边游"分类
- 浏览一日游和周边游产品列表（类型、价格、目的地）
- 点击产品查看详情

### 4.5 评价

- 完成酒店住宿或景点游览后，可在"我的订单"对应订单中发表评价
- 支持五星评分、图文描述和标签选择
- 可对他人评价点赞或举报
- 商家可对评价进行回复

## 5 AI 智能规划

### 5.1 行程生成

1. 点击导航栏"AI 规划"
2. 填写：目的地、出行天数、预算、出行人数、偏好标签
3. 点击"生成行程"
4. 系统在右侧返回按天划分的结构化行程（含活动安排、费用估算）
5. 左侧”历史行程”列表会保存所有已生成记录，点击可回看详情

### 5.2 AI 客服

1. 点击页面右下角的 AI 助手浮窗按钮
2. 输入天气、航班、酒店推荐、路线安排等旅行相关问题
3. AI 助手基于上下文进行多轮对话
4. 对话历史会按会话保存，便于继续追问

> 当 DeepSeek API 不可用时，AI 功能自动降级为静态推荐模板。

## 6 旅行社区

### 6.1 浏览社区

- 导航到"社区"页面
- 双列瀑布流展示游记卡片（标题、封面图、作者、点赞数）
- 点击卡片查看完整内容

### 6.2 发布游记

1. 点击”发布游记”（需登录）
2. 填写标题、正文内容、目的地、标签，并可上传多张图片（支持 jpg/png/gif/webp）
3. 系统发布前自动进行敏感词校验
4. 点击”发布游记”直接发布

### 6.3 互动功能

- **点赞**：点击心形图标
- **收藏**：收藏感兴趣的游记
- **评论**：在游记详情页发表评论，支持回复子评论（二级结构）
- **关注**：关注感兴趣的用户，查看其粉丝和关注列表

## 7 个人主页

1. 点击右上角头像进入个人主页
2. 查看个人资料：昵称、头像、简介、帖子数、关注/粉丝数
3. 点击"编辑资料"可修改昵称、头像、个人简介
4. 导航到"通知中心"查看站内消息，支持单条标记已读、一键清空
5. 导航到"我的收藏"查看所有已收藏的游记

## 8 管理后台

> 仅限管理员用户（role=1）访问

### 8.1 数据仪表盘

访问 `/admin` 后默认进入仪表盘，可查看：

- 总用户数、总订单数、今日订单数、待审核内容数
- 订单趋势、订单类型分布、热门目的地、用户增长图表
- 当前 QPS、接口延迟和告警卡片（为轻量模拟监控指标）

### 8.2 资源管理

- 航班管理：新增、编辑、删除航班资源
- 火车票管理：新增、编辑、删除火车车次资源
- 酒店管理：新增、编辑、删除酒店资源
- 房态管理：进入酒店房态抽屉后，可直接调整房型库存、价格和上下架状态
- 景点管理：新增、编辑、删除景点及门票信息
- 目的地管理：维护平台首页展示的特色目的地城市数据
- 优惠券管理：新增、编辑、删除满减券/折扣券，查看领取记录
- CSV 批量导入：下载各类资源的导入模板，填写数据后一键导入（支持航班、火车、酒店、房型、景点、目的地）

### 8.3 订单流水与退款

- 按订单类型查看全平台订单流水
- 对已取消的交通订单执行退款审批
- 结合状态标签快速区分待支付、已支付、已取消、已退款等状态

### 8.4 内容审核与举报工单

- 审核游记内容，可执行“通过”或“拒绝”
- 查看并处理评价举报工单，记录处理结果

### 8.5 用户管理

- 查看平台用户列表和基础画像信息
- 对违规用户执行“禁用”或“启用”

### 8.6 敏感词管理

添加和管理社区敏感词词库。

### 8.7 操作日志

查看系统操作日志，含操作用户、操作内容、IP、耗时等信息。
