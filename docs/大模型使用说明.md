# TravelMate 大模型使用说明

## 1 概述

本项目在开发过程中使用了大语言模型（LLM）相关技术与工具，主要包括：
- **DeepSeek API**：用于AI行程规划和AI客服两个在线AI功能
- **Claude Code**：用于辅助代码编写、代码审查和问题修复

## 2 AI功能实现（DeepSeek API）

### 2.1 API接入方式

- **协议**：OpenAI兼容的Chat Completions API
- **模型**：`deepseek-chat`
- **端点**：`https://api.deepseek.com/v1/chat/completions`
- **认证**：Bearer Token（通过环境变量 `DEEPSEEK_API_KEY` 配置）
- **HTTP客户端**：Java 11 `java.net.http.HttpClient`
- **超时配置**：连接超时10秒，请求超时30秒

### 2.2 AI行程规划

#### Prompt模板

**System Prompt：**
```
你是一个专业的旅游规划师。请根据用户的需求，生成一份详细的旅游行程规划。
必须以严格的JSON格式返回，结构如下：
{
  "title": "行程标题",
  "summary": "行程摘要",
  "days": [
    {
      "day": 1,
      "date": "2026-06-01",
      "theme": "当天主题",
      "activities": [
        {"time": "09:00", "name": "活动名称", "description": "描述", "type": "景点/餐厅/酒店/交通", "cost": 100}
      ]
    }
  ],
  "totalEstimatedCost": 3000
}
```

**User Prompt构造：**
```
目的地：{destination}，出行天数：{days}天，预算：{budget}元，
出行人数：{peopleCount}人，出行偏好：{preferences}，出发日期：{startDate}
```

**JSON Output约束：** 请求参数中设置 `response_format: {"type": "json_object"}` 强制模型返回合法JSON。

#### 降级策略

当API调用失败（超时、鉴权失败、网络异常等）时，自动返回预设的静态行程模板：
```json
{
  "title": "默认推荐行程",
  "summary": "AI服务暂时不可用，以下为我们为您准备的精选行程模板",
  "days": [...],
  "totalEstimatedCost": 2000
}
```

### 2.3 AI客服多轮对话

#### System Prompt
```
你是TravelMate旅行助手，专注于旅游规划、景点推荐、行程建议等旅行相关问题。
请用友好、专业的语气回答用户问题。
```

#### 多轮对话实现
- 每个会话通过 `sessionId` 标识
- 发起新对话时，从数据库加载最近的20条历史消息
- 将历史消息和当前消息拼接后发送给API
- API返回的内容保存到数据库，关联同一 `sessionId`

#### 降级策略
API不可用时返回："抱歉，AI助手暂时不可用，请稍后再试。"

### 2.4 数据存储

| 表名 | 说明 | 关键字段 |
|------|------|----------|
| tm_ai_plan | AI行程规划记录 | user_id, destination, days, budget, plan_content(JSON) |
| tm_ai_chat | AI客服对话记录 | user_id, session_id, role(user/assistant), content |

### 2.5 响应解析

使用简单的字符串匹配解析JSON响应，定位 `"choices"[...] "message" -> "content"` 字段，无需引入额外的JSON解析库。支持常见转义字符（`\n`、`\t`、`\\`、`\"`）的处理。

## 3 开发过程中大模型辅助

### 3.1 使用工具

- **Claude Code**（Anthropic）：代码编写、重构、测试、文档生成

### 3.2 使用场景

| 场景 | 用途 |
|------|------|
| 代码生成 | 辅助生成Controller、Service、Mapper层代码 |
| 代码审查 | 检查架构问题、安全漏洞、代码重复 |
| 修复建议 | 识别并修复路由配置错误、依赖缺失等问题 |
| 文档生成 | 辅助生成测试报告、部署文档、用户手册 |

### 3.3 使用的Skills

| Skill | 用途 |
|-------|------|
| init | 初始化项目CLAUDE.md |
| Explore agent | 并行分析后端Controller、前端页面、数据库脚本 |

### 3.4 Prompt设计原则

- **JSON Output约束**：行程生成使用 `response_format: {"type": "json_object"}` 确保输出可解析
- **System Prompt分离**：系统提示词与用户输入分离，System Prompt定义角色和输出格式
- **多轮上下文拼接**：客服对话加载历史消息维持上下文一致性
- **降级优先**：所有AI调用都有try-catch和fallback策略，确保核心功能不因AI服务中断而不可用
