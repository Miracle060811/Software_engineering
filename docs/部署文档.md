# TravelMate 部署文档

## 1 环境要求

| 组件     | 版本要求                    | 说明                   |
| -------- | --------------------------- | ---------------------- |
| 操作系统 | Windows 10+ / Linux / macOS | 64位                   |
| JDK      | 21                          | 运行后端服务           |
| MySQL    | 8.0+                        | 数据库                 |
| Redis    | 6.x+                        | 缓存与会话管理         |
| Node.js  | 18+                         | 运行前端               |
| Maven    | 3.8+                        | 后端构建（或使用mvnw） |

## 2 数据库部署

### 2.1 创建数据库

```sql
CREATE DATABASE IF NOT EXISTS travelmate
    DEFAULT CHARACTER SET utf8mb4
    DEFAULT COLLATE utf8mb4_unicode_ci;
```

### 2.2 初始化数据表与Mock数据

PowerShell:

```powershell
Get-Content -Raw .\docs\sql\init.sql | mysql -u root -p
```

CMD:

```bat
mysql -u root -p < docs\sql\init.sql
```

脚本包含20张表和大量Mock数据（航班、火车、酒店、景点等）。

如果你把数据库密码写进 `backend/application-local.yml`，且密码是纯数字或带前导 `0`，请务必写成带引号的字符串，例如 `password: "061010"`。否则 YAML 解析后可能丢失前导 `0`，导致后端连接 MySQL 失败。

若系统提示找不到 `mysql` 命令，可改用 MySQL 安装路径，例如：

```powershell
Get-Content -Raw .\docs\sql\init.sql | & "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -p
```

初始化后可执行以下校验命令：

```powershell
mysql -u root -p -e "USE travelmate; SHOW TABLES LIKE 'tm_user'; SHOW TABLES LIKE 'tm_notification'; SELECT COUNT(*) AS user_count FROM tm_user;"
```

## 3 后端部署

### 3.1 配置环境变量

```powershell
# Windows PowerShell
$env:DEEPSEEK_API_KEY="sk-你的DeepSeek密钥"

# Windows CMD
set DEEPSEEK_API_KEY=sk-你的DeepSeek密钥

# Linux/macOS
export DB_PASSWORD=你的MySQL密码
export DEEPSEEK_API_KEY=sk-你的DeepSeek密钥
```

> `DEEPSEEK_API_KEY` 为可选。未设置时AI行程和客服功能自动降级为预设模板。

### 3.2 方式一：Maven直接运行

```bash
cd backend
mvnw.cmd spring-boot:run "-Dspring-boot.run.arguments=--spring.datasource.password=你的MySQL密码"
```

服务启动在 `http://localhost:8080`。

### 3.3 方式二：打包运行

```bash
cd backend
mvn clean package -DskipTests
java -jar target/backend-0.0.1-SNAPSHOT.jar
```

### 3.4 验证

```bash
curl http://localhost:8080/actuator/health
# 或注册一个测试用户
curl -X POST "http://localhost:8080/user/register?username=admin&password=admin123&role=1"
```

## 4 前端部署

### 4.1 开发模式

```bash
cd frontend
npm install
npm run dev
```

访问 `http://localhost:3000`。

### 4.2 生产构建

```bash
cd frontend
npm run build
```

构建产物在 `frontend/dist/` 目录，部署到任意静态文件服务器（Nginx/Apache）。

Nginx 配置示例：

```nginx
server {
    listen 80;
    server_name localhost;

    location / {
        root /path/to/frontend/dist;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    location /api/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
    }

    location /user/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
    }
}
```

## 5 默认账号

SQL初始化脚本预置管理员账号（密码哈希对应 "admin123"）。若遇到登录问题，手动注册：

```bash
# 管理员
curl -X POST "http://localhost:8080/user/register?username=admin&password=admin123&role=1"

# 普通用户
curl -X POST "http://localhost:8080/user/register?username=test&password=test123&role=0"
```
