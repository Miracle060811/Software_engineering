# TravelMate 大模型使用说明

## 1. 披露范围

本说明区分两类大模型使用：一是 TravelMate 产品内的 AI 行程规划与客服能力；二是课程实践过程中使用生成式 AI 辅助工程工作。正式交付只披露工具、用途、人工复核和安全边界，不提交对话记录、内部草稿、思维链、账号信息或密钥。

## 2. 产品功能中的大模型

| 项目 | 说明 |
| --- | --- |
| 功能 | UC11 AI 行程生成与保存；UC12 AI 客服多轮对话 |
| 输入 | 用户主动提交的目的地、日期、预算、偏好或咨询文本 |
| 输出 | 结构化行程或客服回复；输出不是实时价格、库存或订单承诺 |
| 降级 | API Key 缺失、超时、服务错误或 JSON 不合法时使用本地模板/兜底回复 |
| 数据与密钥 | API Key 仅由环境变量注入，不写入仓库、日志和测试证据 |
| 验证 | 自动化测试覆盖参数、JSON 契约、保存、会话归属、消息顺序及外部失败降级 |

## 3. 工程辅助中的生成式 AI

项目过程中实际使用 TRAE 与 OpenAI Codex CLI 辅助讨论微服务拆分、检查配置、编写或修改部分 Java/Vue/SQL/Kubernetes/PowerShell、形成测试初稿、排查失败及整理文档。它们只作为辅助工具，不作为需求决定者、代码评审者或验收证据来源。

每项建议均由责任成员结合源码和任务书核对；代码须经过编译、单元/集成/E2E、边界与部署门禁；数据库变更须验证空库、Flyway 和生成链；运行结论须来自本地日志、JSON、XML、截图或已保存的流水线记录。无法由证据证明的内容不得写为通过。

## 4. 人工复核与安全边界

- 人工核对类名、接口、表归属、事务、权限、幂等、测试数量、图文引用及许可证；
- 不向模型输入密码、Token、Cookie、私钥、真实身份证号或其他不必要的个人数据；
- `.env`、凭据、内部审阅稿、对话记录、模板占位和临时生成目录不进入最终归档；
- 生成式 AI 不能替代成员确认、项目看板原始截图、Git/流水线事实或实际运行结果；
- 文档中的本说明属于课程要求的主动披露；代码注释、日志和正式图表不额外保留工具口癖或内部过程痕迹。

## 5. 可复核位置
