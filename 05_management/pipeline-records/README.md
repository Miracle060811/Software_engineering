# 每日流水线记录

本目录用于保存 CI/CD 流水线的每日原始记录和证据。记录应与远程平台中的 workflow/run 保持一致，不填写未经实际运行验证的结果。

中期检查的任务编号、REQ/UC、负责人、计划与实际时间、验收条件，以及 commit、PR、测试和文档链接，统一汇总在[任务级证据总表](../任务级证据总表.md)。

## 每天怎么记

1. 从 `_template.md` 复制一份，命名为 `YYYY-MM-DD.md`。
2. 每次由 push、Pull Request 或手动操作触发流水线后，追加一条运行记录。
3. 填写 commit、分支、触发人、运行链接、各阶段结果和失败原因。
4. 截图放入 `screenshots/YYYY-MM-DD/`，文件名建议包含运行编号和阶段名称。
5. 成功和失败的运行都要保留；失败修复后，将两次运行记录互相引用。

## 最低证据要求

- 可访问的流水线运行链接或运行编号
- 对应的 commit SHA 和分支
- 构建、测试、镜像、部署、健康检查各阶段状态
- 失败日志摘要、修复方式和修复后的运行链接
- 测试报告、镜像版本和部署版本（相应阶段启用后填写）

截图只是辅助证据，不能代替仓库中的 workflow 配置、测试代码、日志和原始报告。
