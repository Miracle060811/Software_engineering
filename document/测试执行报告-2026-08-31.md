## 4. 联调发现与修复

| 问题 | 修复 | 回归结果 |
| --- | --- | --- |
| `ResponseStatusException` 被全局异常处理转换为 HTTP 200 | 单独处理并保留原 HTTP 状态 | 错误内部 Token 返回 HTTP 403 |
