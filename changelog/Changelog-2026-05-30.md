## 今日概述

今天的重点是把图片资源和启动方式补齐到“可直接用”的状态。一方面新增了独立的前后端启动脚本，并把 README 的启动参数说明补全；另一方面继续清洗 SQL 中的酒店、游记、景点图片数据，补入一批本地真实图片资源，同时修复旧 `tm_media_asset` 记录在重复导库时归属不更新的问题。

## 变更内容

### feat · New Feature

- **独立启动入口**: 新增 `start-backend.ps1` 和 `start-frontend.ps1`，把原有 `start.ps1` 的参数封装成单服务入口，便于分别启动后端或前端（`start-backend.ps1`、`start-frontend.ps1`）。
- **本地真实图片扩充**: 新增一批酒店和游记封面图到本地资源目录，用于替换部分不稳定、质量不一致或归属不清的外链图片（`frontend/public/images/real/hotels`、`frontend/public/images/real/posts`）。

### fix · Bug Fix

- **媒体资源归属修复**: 将 `tm_media_asset` 的多处插入语句从忽略冲突改为显式更新，补上 `target_type`、`target_id`、`media_type` 等字段的覆盖，修复重复导库时旧图片仍挂在错误对象上的问题（`docs/sql/init.sql`）。
- **酒店封面批量纠偏**: 补齐并替换酒店 21-26、31-36、41-52 等多批次封面，优先切换到本地真实图片，减少无图、错图和失效外链（`docs/sql/init.sql`、`frontend/public/images/real/hotels`）。
- **游记与景点封面纠偏**: 将北京、上海、江南串线、武汉等游记封面替换为更贴合内容的本地图片，并修复部分景点最终封面兜底映射（`docs/sql/init.sql`、`frontend/public/images/real/posts`）。

### docs · Documentation

- **启动说明完善**: README 增加独立启动脚本的用法、参数说明和与 `start.ps1` 的关系，降低同学本地启动时的理解成本（`README.md`）。
- **日志初版回填**: 当天先生成了一版 0530 日志，当前版本在此基础上按实际提交重新补全（`Changelog-2026-05-30.md`）。
